# Contributing a template

1. One directory per template, named like the template (`name` in `template.yaml`).
2. Pin every image by digest: `docker.io/owner/image:tag@sha256:...`.
3. Fill in `upstream` (project, URL, licence). If you adapted a Coolify or Dokploy template, name it in `upstream.adaptedFrom` with its licence.
4. Declare what an agent needs: settings it may change (and which values need a human's approval), actions, secrets (generated by the server or entered by a human; never put a secret value in a template), what to back up, and setup steps for the human.
5. Bump `version` on every change to a template.

CI validates every template on each pull request. A template is offered to installs once it has been deployed and checked on real servers (verified tier).
